# My Python Projects

These are four beginner Python projects I built to practice programming, problem-solving, and basic cybersecurity skills.

## Projects

- **Aim Tester (`Aim+.py`):** A Pygame game where you click moving targets to earn points in 30 seconds.
- **Computer Parts Quiz (`Quiz.py`):** A 10-question quiz about computer hardware that shows your final score.
- **Password Manager (`PasswordSafe.py`):** A simple program that saves and views encrypted passwords using Fernet.
- **Dice Guessing Game (`DiceRoll.py`):** Guess a number from 1 to 6 and earn points when you match the dice roll.

## How to Run

1. Install Python 3.
2. Install the required libraries:
   ```bash
   py -m pip install pygame cryptography
   ```
3. Run a project, for example:
   ```bash
   py Quiz.py
   ```
   Replace `Quiz.py` with `Aim+.py`, `PasswordSafe.py`, or `DiceRoll.py` to try another project.
